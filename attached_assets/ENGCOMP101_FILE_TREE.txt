ARTIFACT 2: artifacts/api-server/  - BACKEND (Express 5 + Node.js)

artifacts/api-server/
|
+-- build.mjs                   esbuild bundler config (Pino plugin).
|                               Bundles src/index.ts + worker scripts to
|                               dist/index.mjs and pino-* worker bundles.
|
+-- package.json                @workspace/api-server. Depends on
|                               @workspace/api-zod, @workspace/db,
|                               @workspace/integrations-anthropic-ai.
|                               Runtime: express, drizzle-orm, pino, cors,
|                               cookie-parser.
|
+-- src/
    |
    +-- index.ts
    |   Server entry point. Reads PORT env, calls createApp(), listens,
    |   logs startup banner.
    |
    +-- app.ts
    |   Express app factory. Middleware order:
    |     1. pinoHttp (request logging)
    |     2. cors (allow same-origin + dev preview)
    |     3. cookieParser (signed cookie support)
    |     4. express.json + urlencoded
    |     5. attachSession (parses session cookie -> req.studentId)
    |     6. mount /api -> routes/index.ts
    |     7. error handler
    |
    +-- types.d.ts
    |   Augments Express Request to add `studentId?: number` and
    |   `log: pino.Logger`.
    |
    +-- middlewares/
    |   |
    |   +-- session.ts
    |       Cookie-based session layer (no password):
    |         - attachSession()      decodes signed cookie -> req.studentId
    |         - requireStudent()     401 if no studentId
    |         - requireAdmin()       403 if not isAdmin
    |         - setSessionCookie()   issues HttpOnly signed cookie
    |         - clearSessionCookie() blanks cookie on logout
    |
    +-- routes/
    |   |
    |   +-- index.ts
    |   |   Aggregator. Mounts every sub-router under /api:
    |   |     /healthz, /auth/*, /progress/*, /submissions/*, /tutor/*,
    |   |     /drafts/*, /canvas/*, /ai/*, /integrity/*, /admin/*,
    |   |     /diagnostic/*
    |   |
    |   +-- health.ts
    |   |   GET  /healthz                        -> { status: "ok" }
    |   |
    |   +-- auth.ts
    |   |   POST /auth/login                     idempotent register-or-login
    |   |   POST /auth/logout                    clears cookie
    |   |   GET  /auth/me                        current student or null
    |   |
    |   +-- progress.ts
    |   |   GET  /progress                       completedModuleIds + intro
    |   |   POST /progress/intro                 saves student.intro
    |   |
    |   +-- integrity.ts
    |   |   POST /integrity/ack                  timestamps integrityAckAt
    |   |   POST /admin/bootstrap                first caller becomes admin
    |   |
    |   +-- submissions.ts
    |   |   GET  /submissions                          student's own
    |   |   POST /submissions                          final submit + AI check
    |   |   GET  /submissions/module/:moduleId         latest for module
    |   |   - Enforces sequential gating (prior modules done)
    |   |   - Triggers async runAICheck() (GPTZero) -> aiStatus pending->done
    |   |
    |   +-- drafts.ts                            ONE-ROUND DRAFT FEEDBACK
    |   |   GET  /drafts/:moduleId               fetch draft + any feedback
    |   |   POST /drafts/:moduleId               submit for AI feedback,
    |   |                                        locks draft on success
    |   |
    |   +-- canvas.ts                            LIVE INTEGRITY CANVAS
    |   |   GET  /canvas/:moduleId               unsaved work + history
    |   |   POST /canvas/:moduleId/autosave      content + keystrokes +
    |   |                                        scoreHistory
    |   |   POST /canvas/:moduleId/score         GPTZero proxy (skipped
    |   |                                        when student.accommodated)
    |   |
    |   +-- tutor.ts                             AI TUTOR (SOCRATIC)
    |   |   GET  /tutor/:moduleId/conversation   fetch or create thread
    |   |   POST /tutor/:moduleId/message        SSE stream from Claude
    |   |   POST /tutor/:moduleId/critique       generate mediocre answer
    |   |
    |   +-- ai-actions.ts                        ON-DEMAND AI HELPERS
    |   |   POST /ai/:moduleId/:action           SSE-stream one of:
    |   |     - study-guide   instructor-style summary
    |   |     - tutorial      step-by-step walkthrough
    |   |     - podcast       350-450 word audio script
    |   |     - rewrite       reading rewritten for clarity
    |   |     - read-draft    formative feedback on student draft
    |   |
    |   +-- admin.ts                             INSTRUCTOR DASHBOARD
    |   |   GET  /admin/submissions              all submissions, all students
    |   |   GET  /admin/submissions/:id          full detail + keystrokes +
    |   |                                        scoreHistory + activityReport
    |   |   POST /admin/submissions/:id/review   set reviewStatus
    |   |   GET  /admin/students                 student roster
    |   |   POST /admin/students/:id/accommodate toggle accommodated flag
    |   |
    |   +-- diagnostic.ts
    |       POST /diagnostic/run                 e2e self-test:
    |         - env vars present
    |         - DB ping
    |         - Anthropic ping
    |         - functional fake-student flow (login -> canvas -> submit)
    |
    +-- lib/
        |
        +==================================================================+
        |          AI TUTOR + INTEGRITY MONITORING SUPPORT LAYER           |
        +==================================================================+
        |
        +-- curriculum.ts
        |   Mirror of artifacts/phil-101/src/data/curriculum.ts.
        |   Imported by tutor.ts, drafts.ts, ai-actions.ts so the AI sees
        |   the same module text the student sees. Exports moduleById(),
        |   moduleIndexById(), and the 14-module array.
        |
        +-- gptzero.ts
        |   Wrapper around the GPTZero detection API.
        |   - scoreText(text) -> { aiScore, aiClass, raw }
        |   - Used by submissions.ts (final score on submit) and
        |     canvas.ts (live throttled score during typing)
        |
        +-- activityReport.ts
        |   Heuristic analyzer over keystroke + score telemetry. Detects:
        |     - sustainedRed   periods of high AI probability
        |     - burstTyping    suspicious word-per-second spikes
        |     - pasteishBursts large chunks appearing without keystrokes
        |   Output stored in submissions.activityReport for instructor view.
        |
        +-- logger.ts
            Pino logger factory. PII redaction (email/cookie), pretty
            transport in development, JSON in production.

DATA + CONTROL FLOWS (HOW THE PARTS TALK TO EACH OTHER)
================================================================================

+----------------------------------------------------------------------------+
|                          1. STUDENT WRITING FLOW                          |
+----------------------------------------------------------------------------+

   Student opens module M
            |
            v
   IntegrityDisclosure modal (first time only)
   POST /integrity/ack  -> students.integrityAckAt
            |
            v
   +----------------------+      +-------------------------+
   |  DraftWorkshop       |      |  IntegrityCanvas        |
   |  (Box 1 - sandbox)   |      |  (Box 2 - monitored)    |
   |                      |      |                         |
   |  free paste / edit   |      |  keystrokes captured    |
   |                      |      |  paste-from-outside     |
   |  POST /drafts/:M     |      |  blocked                |
   |    body: { content } |      |                         |
   |  ->  Anthropic       |      |  POST /canvas/:M/score  |
   |  ->  Markdown        |      |    -> GPTZero proxy     |
   |      feedback        |      |    -> live traffic-light|
   |                      |      |                         |
   |  drafts.locked=true  |      |  POST /canvas/:M/auto-  |
   |  (one round only)    |      |       save (content +   |
   |                      |      |       keystrokes +      |
   |                      |      |       scoreHistory)     |
   +----------------------+      +-------------------------+
                                          |
                                          v
                                 POST /submissions
                                   { moduleId, content,
                                     keystrokes, scoreHistory }
                                          |
                                          v
                                 + sequential-gating check
                                   (all prior modules done?)
                                 + insert submissions row
                                 + spawn async runAICheck:
                                     gptzero.scoreText()
                                     -> aiScore, aiClass
                                     -> activityReport()
                                     -> aiStatus = "completed"
                                          |
                                          v
                                 GET /progress now lists M
                                 as completed -> next unlocks


+----------------------------------------------------------------------------+
|                       2. AI TUTOR (SSE STREAMING) FLOW                    |
+----------------------------------------------------------------------------+

   tutor-panel.tsx / tutor.tsx
            |
   GET /tutor/:moduleId/conversation
            |  (creates row in tutor_conversations if absent)
            v
   user types question, hits send
            |
   POST /tutor/:moduleId/message         (text/event-stream response)
            |
   server: build system prompt =
     "You are the AI Tutor for English Composition 101 ..."
     + courseOverview() (titles of all 14 modules)
     + CURRENT MODULE block (title, objectives, reading, assignment)
     + studentIntro
     + prior tutor_messages
            |
   server: anthropic.messages.stream({ model: "claude-sonnet-4-...",
                                       max_tokens: 8192, messages })
            |
   for each content_block_delta -> res.write("data: { content }\n\n")
                                  -> persist to fullResponse
            |
   on stream end -> insert into tutor_messages + send "data: { done: true }"
            |
            v
   client lib/sse.ts streams chunks into the message bubble


+----------------------------------------------------------------------------+
|                        3. ON-DEMAND AI ACTIONS FLOW                       |
+----------------------------------------------------------------------------+

   inline-ai-action.tsx (in module-detail.tsx)
            |
   POST /ai/:moduleId/:action       action is one of:
            |                          study-guide | tutorial | podcast |
            |                          rewrite     | read-draft
            v
   server: routes/ai-actions.ts builds {system, user, maxTokens}
            based on action + curriculum.moduleById(moduleId)
            |
            v
   anthropic.messages.stream() -> text/event-stream -> Markdown rendered


+----------------------------------------------------------------------------+
|                       4. ADMIN REVIEW FLOW                                |
+----------------------------------------------------------------------------+

   First instructor visits /admin/submissions
            |
   POST /admin/bootstrap (only succeeds if no admins exist yet)
            |  students.isAdmin = true for caller
            v
   GET /admin/submissions  -> table of every submission
            |
   click row -> GET /admin/submissions/:id
            |
            v
   admin-submission-detail.tsx renders:
     - keystroke replay (timestamps + values)
     - GPTZero score history sparkline
     - activityReport bullets (sustainedRed / burstTyping / pasteishBursts)
            |

================================================================================
KEY NOTES FOR FUTURE ENHANCEMENT
================================================================================

1. CURRICULUM IS DUAL-MIRRORED.
   artifacts/phil-101/src/data/curriculum.ts must stay byte-identical to
   artifacts/api-server/src/lib/curriculum.ts (api-server's mirror has one
   extra header comment). Any module edit must touch both.

2. API CONTRACT IS CODEGEN.
   Hand edits to lib/api-zod/ and lib/api-client-react/generated/* will be
   overwritten. Edit lib/api-spec/openapi.yaml then run:
     pnpm --filter @workspace/api-spec run codegen
   Endpoints not in openapi.yaml use lib/integrity-api.ts (hand fetch).

3. SEQUENTIAL MODULE GATING.
   Enforced server-side in routes/submissions.ts based on completedModuleIds
   in progress.ts. Client respects same logic in modules.tsx. Admin override
   is `?admin=true` query param + isAdmin server flag.

4. SSE STREAMING ENDPOINTS.
   Tutor and AI-actions return text/event-stream. Orval cannot generate a
   usable client for these - they are consumed by lib/sse.ts on the client.

5. INTEGRITY MONITORING IS COMPOSED OF FIVE COOPERATING PIECES:
   - integrity-disclosure.tsx        (gate / consent)
   - draft-workshop.tsx              (Box 1 - one feedback round)
   - integrity-canvas.tsx            (Box 2 - keystroke capture, paste block)
   - lib/gptzero.ts                  (live + final AI scoring)
   - lib/activityReport.ts           (post-hoc heuristic flags)
   Disabling any single piece silently degrades the others.

6. AUTH IS PASSWORDLESS.
   POST /auth/login with email + name is idempotent (creates or matches).
   Single signed HttpOnly cookie carries studentId. No password storage.

7. ADMIN IS BOOTSTRAPPED.
   First caller of POST /admin/bootstrap (when no admins exist) becomes the
   admin. Subsequent calls are rejected.

8. EVERY AI PROMPT REFERENCES THE CURRICULUM.
   tutor.ts, drafts.ts, ai-actions.ts all import moduleById() so the AI's
   system prompt always contains the exact module title, objectives, reading,
   and assignment text the student is seeing.
